# SatisFlow

Satisfactory + React Flow = SatisFlow

## Icons

To extract icons, follow the instructions in [this article](https://docs.ficsit.app/satisfactory-modding/latest/Development/ExtractGameFiles.html). Open the `.utoc` file.

Open Search and use the regex `(Christmas|Resource).*/IconDesc_` to get all the icons.

Export them `./scripts/export`.
